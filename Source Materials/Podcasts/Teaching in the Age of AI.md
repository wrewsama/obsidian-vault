- The _act_ of note taking is beneficial for retention, prefer writing over typing
- feedback loops should be as tight as possible
    - LLM feedback can be useful, but beware of false positives
- utilise Claude Code's "learning" output style
- difficulty of reviewing code
    - building a mental model of the problem domain after only seeing the finished result
    - PR reviews and using LLMs have the same problem
- when teaching
    - introduce the motivating problem before the tool/concept you're trying to teach
    - set concrete learning goals for each lesson
    - manage cognitive load, don't try to introduce multiple things at the same time
- note: the above can be applied to learning as well
