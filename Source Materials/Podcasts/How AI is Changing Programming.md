- you want agents to have tighter restrictions than humans
    - think about them adversarially
    - sandbox by allowlisting, NOT denylisting
- agents are perpetual beginners, they need to "relearn" on every run
    - e.g. build systems, version control, initial setup
    - make it simpler for them to get started
- coding: agents do the implementation, humans make sure it's done right
- design: humans collaborate with the agent
- difficulty of reviewing agentic code: agents make unique types of mistakes that humans won't => hard to expect
- when trying to understand a system, consider using LLMs to produce visualisations instead of just text
