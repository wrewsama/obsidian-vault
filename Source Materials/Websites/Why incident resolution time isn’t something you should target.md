- **core issue: the time taken to resolve an incident depends on the type of incident that occurs** => meeting the target doesn't correspond to improvement
- set targets for things that won't change from incident to incident, e.g.
    - pager response time
    - channel staffing time
    - severity assessment
- resolution time should still be tracked, just don't set targets based on it
- use the resolution times to track trends across quarters and investigate outliers
    - can reveal systemic issues e.g. lack of tooling
